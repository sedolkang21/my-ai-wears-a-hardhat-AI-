# 스킨

이 폴더에 `이름.json`을 넣으면 펫의 모습을 바꿔 끼울 수 있다. 이미지 파일은 쓰지 않고, 글자로 픽셀을 찍는다.

## 쓰는 법

1. 이 폴더에 `myskin.json`을 만든다. `slime.json`을 복사해서 고치면 쉽다.
   들어 있는 스킨: `slime`(물방울), `rabbit`(토끼), `cat`(고양이). 토끼와 고양이는 0.2.0까지 GPT 펫과 기타 AI 펫의 기본 모습이었다.
2. `config/pets.json`에서 바꾸고 싶은 펫에 `"skin": "myskin"`을 넣는다.

   ```json
   "gpt": { "label": { "ko": "GPT 펫", "en": "GPT pet" }, "species": "robot", "skin": "rabbit", ... }
   ```

3. 뷰어를 새로 고친다.

## 형식

| 항목 | 뜻 |
| --- | --- |
| `body` | 몸. 글자 16개짜리 줄 13개(가로 16픽셀, 위에서 아래로). |
| `legs` | 다리 그림 4장. 한 장은 글자 16개짜리 줄 3개다. 걷을 때 0, 1, 2, 3 순서로 돌아간다. |
| `eyes` | 두 눈의 가로 위치(0부터 센다). 예: `[5, 10]` |
| `eyeY` | 눈의 세로 위치. 눈은 세로 2픽셀로 그린다. |
| `hatY` | 모자 맨 아랫줄이 놓이는 세로 위치. |
| `helmet` | `true`면 공사 헬멧을 씌운다. 몸의 2~12번째 가로 칸, 0~5번째 줄을 덮는다. `false`면 머리 가운데(4~11번째 칸, 2~4번째 줄)에 작은 안전모를 씌운다. |

몸과 다리에 쓰는 글자:

| 글자 | 색 |
| --- | --- |
| `.` | 비움 |
| `o` | 몸 색 (`pets.json`의 `colors.base`) |
| `d` | 그늘 (`colors.shade`) |
| `l` | 밝은 곳 (`colors.light`) |
| `k` | 먹색 |
| `w` | 흰색 |
| `p` | 분홍 |
| `y` | 노랑 |

눈, 표정, 모자, 도구는 뷰어가 덧그린다. 눈 자리는 몸 색으로 채워 둔다.

## 주의

- 파일 하나는 64KB까지, 스킨은 20개까지 읽는다.
- 서브에이전트(작은 펫)는 스킨을 따르지 않고 기본 모습으로 나온다.
- 남의 캐릭터를 그대로 옮긴 스킨은 혼자 쓸 때만 쓰고, 공개 배포에는 넣지 않는다.
